# Logotipo oficial

Nenhum arquivo de logotipo foi encontrado no material recebido (apenas fotos em que a marca aparece nas bombas, no totem e nos uniformes).

Coloque aqui o arquivo oficial — de preferência **SVG** — e ele será usado automaticamente no cabeçalho, no rodapé e na página 404:

| Arquivo | Uso |
| --- | --- |
| `logo-light.svg` | Versão para fundos escuros (cabeçalho, rodapé) |
| `logo-dark.svg` | Versão para fundos claros |
| `logo.svg` | Uma única versão para os dois casos |

Também aceita `.png` ou `.webp` com fundo transparente.

Depois, substitua também `public/favicon.svg` pelo símbolo oficial e rode `npm run media` para regenerar os ícones PNG.
